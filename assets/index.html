Da planilha ao Parquet

Os arquivos de origem são carregados e convertidos para um formato adequado ao processamento analítico.

01 · Planilhas / CSVClientes, produtos, vendas e preços.
02 · Python + PandasLeitura dos arquivos e conversão.
03 · ParquetMesmo nome do arquivo de origem, com extensão .parquet.
Por que Parquet?
Formato colunar adequado para dados analíticos e processamento eficiente. Os arquivos também podem ser armazenados no Data Lake.

// transformações

Camadas do Warehouse

Cada camada possui uma responsabilidade clara dentro do processo de transformação.

🔶 BRONZE
Limpeza e padronização. Estrutura os dados mantendo proximidade com a origem.
⬜ SILVER
Aplica regras de negócio, relacionamentos e enriquecimento dos dados.
🏆 GOLD
Modelos analíticos, agregações, métricas e dados preparados para consumo.
// fluxo

Do dado bruto ao Analytics

Fluxo resumido de execução do projeto.

01
Receber dados
Planilhas e arquivos CSV são colocados na área de entrada.
02
Converter
Python e Pandas convertem os CSVs para Parquet.
03
Persistir
Arquivos e registros são armazenados para manter a origem e o histórico.
04
Transformar
O dbt organiza as transformações no Warehouse: Bronze → Silver → Gold.
05
Consumir
A camada Gold disponibiliza dados preparados para análises e indicadores.
